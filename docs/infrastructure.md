# BBI Marketing

> Full documentation index: [README.md](README.md). Narrative overview: [overview.md](overview.md). These diagrams are the **network** view only.

BBI Marketing is an authorized vendor of Domino’s for marketing. Their clientele consists mainly of Domino’s franchisees who own 1 or more brick-and-mortar store locations. BBI has ETL processes which pull in POS data (as well as others) from these locations which it uses for marketing information.

At BBI, the ETL process is handled by PHP scripts which runs on a cron schedule. They connect to `pulse` (Domino's proprietary software suite that runs in store locations). 

**Currently PHP scripts runs on physical machines on-premises and their priority is to move it into the cloud (the applications, the database data, the file storage).**
